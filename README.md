## 3. 批量擴充機制（本次題量放大 3.3 倍的做法）

核心思路：**先寫「知識點表」，再讓程式把每個知識點變成 2–4 道不同角度的題**，
所以題量放大不代表重複，而是覆蓋面放大。

```
tools/facts/*.js（知識點表）
      │  每列：n 名稱、t 章、g 特徵／功效／定位、i 主治／治法、s 用法／組成
      ▼
node tools/generate.js
      │  · 正向題：名 → 敘述（中藥「麻黃」的功效是…）
      │  · 反向題：敘述 → 名（治療「…」宜選用的藥物是…）
      │  · 附加題：用法注意／方劑組成／特定穴屬性
      │  · 針灸病案：病症 → 取穴
      ▼
data/1N-gen-*.js（每次重跑覆寫，不動手寫題）
      ▼
node tools/build.js（結構檢查、重複檢查、匯出 CSV／JSON）
```

**不重複的把關方式**

| 風險 | 處理 |
|---|---|
| 同一知識點出兩題 | 正向／反向／附加各取不同欄位，同一欄位只出一次 |
| 選項答案不唯一 | 若某段描述在表中出現兩次以上（多個藥、多個方共用一个主治），該知識點標為歧義直接略過 |
| 選項型態不一致 | 反向題的干擾項只取「名稱」，正向題只取「描述」，不會出現藥名與主治混在同題 |
| 答案位置偏一端 | 以題幹雜湊當種子洗牌，答案 A/B/C/D 分布趨近均勻（生成題與手寫題合計趨近均勻） |
| 干擾項太遠、一看就錯 | 「同章優先」挑干擾（同為解表藥、同為補益劑），難度貼近真題；反向題改「他章優先」避免同章近義 |

**要再加題，只要扩知識點表**（不用改程式）：

```js
// tools/facts/materia.js 內新增一列
{n:"麻黃",t:"解表藥",g:"發汗解表、宣肺平喘、利水消腫",i:"風寒表實無汗、肺氣壅遏喘咳",s:"不宜久煎"},
```

存檔 → `node tools/generate.js` → `node tools/build.js` → 重新整理 `index.html`，題目自動多出 3–4 道。

## 4. 資料結構

### 4.1 科目登錄表 `window.TCM_SUBJECTS`（在 `data.js`）

| 欄位 | 說明 |
|---|---|
| `id` | 科目代碼：`diagnosis`／`internal`／`basic`／`materia`／`formula`／`acupuncture`／`surgery`／`pediatrics`／`gynecology` |
| `name` | 顯示名稱 |
| `open` | `true` 才可在介面選取並練習（現九科全為 `true`） |
| `base` | 教材基準說明 |
| `n` | 題數（由 `build.js` 算出，不必手填） |

### 4.2 題目欄位

| 欄位 | 型別 | 說明 |
|---|---|---|
| `id` | string | 科目前綴＋流水號；生成題為 `前綴-G001`；**新增題目往下續號，不要改舊號** |
| `sub` | string | 科目 id |
| `ch` | string | 章名（用章名而非章號，避免版本改編後對不上） |
| `type` | string | `A1`／`A2`／`B1`／`A3` |
| `diff` | 1–3 | 難度 |
| `stem` | string | 題幹 |
| `opts` | string[4] | 四個選項，**不含 A/B/C/D 前綴**，由介面自動標 |
| `ans` | string | `A`／`B`／`C`／`D` |
| `exp` | string | 解析（一句話講清辨證／鑑別要點） |
| `tags` | string[] | 知識點標籤，供日後檢索／錯題歸因 |
| `case` | string（選填） | 病案描述，A2／A3 使用；介面渲染成獨立「病案」區塊 |
| `groupLabel` | string（選填） | 題組說明，B1 使用，如「（1）～（4）題共用備選答案」 |

### 4.3 題型

| 代碼 | 全稱 | 資料長相 |
|---|---|---|
| `A1` | 單句型最佳選擇題 | 一題一列，四個選項 |
| `A2` | 病例摘要型最佳選擇題 | 有 `case`，題幹只問「其證候是」 |
| `B1` | 標準配伍題 | 同組 4 子題共用同一組 `opts`，`stem` 以（1）（2）編號 |
| `A3` | 病例組題 | 同一病案連續 3 問，每列各自帶 `case`（可亂序作答） |

新增一題的範本（貼在該科檔案陣列內）：

```js
{id:"JC-101",sub:"basic",ch:"藏象",type:"A1",diff:2,
 stem:"題幹……",
 opts:["選項一","選項二","選項三","選項四"],ans:"B",
 exp:"解析……",tags:["藏象"]},
```

## 5. 介面功能

- 科目卡切換（九科，**固定兩欄一排**，卡上直接顯示該科題數），章節多選、題數（全部／10／20／30／50）、隨機排序、只練錯題
- **卡片複習（選擇題卡）**：一題一張卡，題幹居中、四個選項；點選即判對錯並預記（對→確定、錯→不熟），解析隨即在卡內展開。**不管對錯，都還能按「不熟／確定」改判**（例如答對但自己覺得不熟、或答錯但只是看錯字）；未作答也可直接自評。滑動＝判定或換卡，另有「下一張」按鈕。卡片取自題庫（可依科目／章節／題數篩選），不熟的卡存本機，可「再複習不熟」
- 作答即時判對錯、解析同步展開；鍵盤 `1–4` 作答、`Enter` 前進、`←` 回上一題
- **上一題**：回頭看已作答的題目，選項與解析原樣還原（不會重複計分，作答後不可改答案）
- **結束本回**：中途跳出練習，直接進成績頁；一題都還沒答則回首頁設定
- 病案區塊（A2／A3）與配伍共用選項標籤（B1）獨立版式
- 錯題自動入池（答對即移出），存本機 `localStorage`，跨次保留
- **逐項辨析**：作答後除了正解解析，每個干擾選項也標出它其實屬於哪個方／藥／穴／證（例：「C 此為『當歸四逆湯』的主治：血虛寒厥證」）。2182 題生成題全覆蓋，並寫入 `exports` 的「其他選項辨析」欄
- 試題頁支援**左右滑動換題**（左滑下一題、右滑上一題，位移需超過 56px 且以水平為主；未作答時左滑不生效，與「下一題」按鈕一致）
- 手機上**雙擊／雙指縮放已關閉**（`viewport` 鎖定、按鈕 `touch-action:manipulation`），頁面不會被誤觸放大位移
- 成績頁：正確率環、章節正確率長條、錯題回顧（含正解與解析）、一鍵再練錯題

## 6. 擴充方式

1. **加題量（推薦）**：在 `tools/facts/` 對應科目檔案加知識點列 → 重跑 `node tools/generate.js`（緒論／古籍用 `node tools/generate-extra.js`）＋ `node tools/build.js`。
2. **加古籍原文**：在 `tools/facts/classics.js` 追加 `k:"quote"`（n 原文／b 書名／g 篇名／i 闡釋）或 `k:"book"`（n 書名／g 作者年代／i 貢獻）列 → 重跑 `generate-extra.js`。
3. **加新科目**：於 `data.js` 的 `TCM_SUBJECTS` 登錄（`open: true`）→ 建 `tools/facts/新科.js` → 在 `generate.js` 的 `CFG` 加一段（題幹模板＋解析模板＋`lbl` 欄位名稱）→ `index.html` 加 script 標籤與 `CHAPTER_MAP`。
4. **手動加單題**：直接在 `data/0N-*.js` 陣列內續號新增。
5. 每次改完跑 `node tools/build.js`，看「異常」是否為「無」，再重新整理 `index.html`。

- 生成題的題幹模板較固定（「中藥 X 的功效是」「腧穴 X 的定位是」等），命題角度尚未涵蓋鑑別用藥、配伍意義、禁忌、方證比較。要更接近真題，需在知識點表加「鑑別」「配伍」類欄位與新模板。
- 手寫題的正解常是選項中較長者（約 86%），雖已重排 A/B/C/D 位置，長度仍是一條可辨識線索；生成題此比例為 40%（四選一基準為 25%）。
- **A2／B1／A3 仍只存在於診斷學、內科學、基礎理論**，其餘六科目前全為 A1。
- 中醫內科學已補「證型→治法＋代表方」類題（109 個證型），但代表方以教材通行為主，具體加減仍需對版本校對。
- **逐項辨析只覆蓋 2127 題生成題**（與知識點表同源，干擾項可精確歸屬）；其餘 718 題手寫題的選項屬自由撰寫，僅有整體解析，未逐項標注（部分選項若在別題是正解會自動標出考點）。
- 古籍章節的原文出自通行本（素問／靈樞篇名、傷寒論條文、金匱篇章、溫病條辨等），**篇名與條文仍建議對你手上教材核對一次**；同一原文在不同版本有字句差異。
- A2／A3 的病案是依典型證候寫成的**模擬病例**，不是真實病歷，僅供練辨證，不作臨床依據。
- B1／A3 題組的子題各自獨立計分；抽題會保留同組題目，不會被拆散。
- 章節表現只統計本章已作答題目，未作答章節不列入。
- 錯題池存於瀏覽器；換瀏覽器或清快取會清空，重要紀錄請以 `exports/` 內的檔案為母本。
- 本題庫為學習練習用途，不作為臨床診斷依據。
